# Export log

A dated public log of exports to formalization platforms and of fixes to the export tooling, newest
last. Names and release numbers follow [NAMING.md](NAMING.md) and [VERSIONING.md](VERSIONING.md).

| Date | What |
|---|---|
| 2026-10-12 | A private pilot exported ✱1–✱5 to Prove2Me: 4 definition bundles and 196 theorems (✱1·2–✱1·6, the 188 theorems of ✱2–✱5, and three results about the system: soundness, completeness, and that the one-letter variant of ✱1·4 in the Gutenberg transcription is not a theorem). All 196 were proved on the platform, in its Lean v4.33.1 environment. The pilot used the repository's own Lean names (`PM.t2_01`, …), not the export names of NAMING.md, and it is not a release. |
| 2026-10-12 | The platform refuses `macro` in submissions, so the pilot's exporter (not yet in this repository) expands the repository's two tactic macros in the proofs it submits. |
| 2026-10-12 | One exported declaration, `upd_self` in PM/Complete.lean, relied on an auto-bound implicit (`b`); fixed in the repository on 2026-10-13 by declaring the binder `{b : Bool}`. |
| 2026-10-13 | Export names changed, before any release, to PM's number and PM's own name only (`PM.star2_01_abs`); Lean and Mathlib counterparts of ✱1–✱5 recorded as metadata; the lock of released names now binds each name to digests of its statement and definitions. Nothing has been released under either scheme. |
| 2026-10-13 | The exporter is now in this repository, [scripts/prove2me/](../scripts/prove2me/README.md), with the checks it runs before upload; it reads card names from data/export_names.json and counterparts from data/naming/counterparts.json, and makes no network call (uploading is done separately). Changes from the pilot's: cards are named by their export names, and references between cards in solutions are renamed to match; ✱1·2–✱1·6 state the constructors of `PM.Thm` as declared, where the pilot stated them through an overlay outside the repository; the workaround for `upd_self` is gone with its fix; and the definition bundles are named `PM_core_<words>` ([NAMING.md](NAMING.md#definition-bundles)). |
| 2026-10-13 | **Release 1.0.0+m.7d40537313d3 prepared, not yet public.** PM ✱1–✱5 on Prove2Me: 196 cards, all labelled DRAFT (✱1·2–✱1·6, the 188 numbered propositions of ✱2–✱5, and three results about the system: soundness, completeness, and that the one-letter variant of ✱1·4 in the Gutenberg transcription is not a theorem), and 4 definition bundles, exported from the commit that adds this entry. Names: the 196 rows of data/export_names.lock, whose Merkle root is the build metadata ([VERSIONING.md](VERSIONING.md#the-merkle-root)); no reading is used. Environment: Prove2Me's default, Lean v4.33.1 with Mathlib 0df444a (the files import no Mathlib). Checked with that Lean before upload: every file compiles; each card's type equals its declaration's in the repository; and each card's statement and definitions digests, computed from the uploaded files, equal the locked ones, computed in the repository with Lean v4.34.1. It becomes public when the maintainer approves; that date will be added here. |
